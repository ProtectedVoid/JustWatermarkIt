# Just Watermark It!

It is a very small utility software made for watermarking several photos at once.
That's all? Yes. But it has options and funny buttons so... Stay around

## How does it work ?
* Select a source folder
* Select a destination folder
* Select a file, used as a watermark
And that basically fits the job. But that's not all of the funny buttons!

## Features
* 2 mods for applying the watermark :
  * Corner : the watermark will be added in the bottom-left corner, small size, light
  * Large : the watermark will be put across the whole photo, taking the maximum of space
* You can select which opacity you want, using the slider. 30% is globaly fine
* You can choose, after processing your pictures, to move originals in a different folder. For classifying, archiving, ...
* Also, you have the option to rename your outputs files, so they never erase or get erased by the original ones.
